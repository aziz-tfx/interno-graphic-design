# INTERNO School — лендинг курса по графическому дизайну

Одностраничный лендинг для таргетированной рекламы курса «Графический дизайнер» INTERNO School.

## Структура

Весь лендинг — один самодостаточный файл `index.html` (стили и скрипты инлайном), что упрощает деплой на любой хостинг: GitHub Pages, Vercel, Netlify, Tilda (HTML-блок) и т.д.

## Блоки страницы

1. **Hero** — оффер, CTA «Бесплатный урок», ключевые цифры
2. **Бегущая строка** — навыки/темы курса
3. **Кому подойдёт** — 3 сегмента целевой аудитории
4. **Программа** — 5 модулей (аккордеон)
5. **Результаты** — что получит студент
6. **Инструменты** — Figma, Photoshop, Illustrator и др.
7. **Отзывы** — социальное доказательство
8. **Оффер + форма заявки** — цена со скидкой, таймер, буллеты, лид-форма
9. **FAQ** — отработка возражений
10. **Финальный CTA** + футер

## Что настроить перед запуском трафика

- **Отправка лидов**: в `index.html` найдите обработчик `lead-form` и подставьте свой endpoint (CRM, Telegram-бот, amoCRM, Google Sheets).
- **Пиксели**: вставьте коды Meta Pixel / VK Ads / Яндекс.Метрики перед `</body>` (см. комментарий в конце файла). Событие конверсии `Lead` уже отправляется при сабмите формы.
- **Цены и даты**: актуализируйте цену, размер скидки и дедлайн таймера.
- **Политика конфиденциальности**: замените ссылку-заглушку в форме на реальную страницу.
